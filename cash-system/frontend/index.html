API Documentation

GET /api/services

Get list of available services and pricing

curl http://localhost:8000/api/services

POST /api/quote

Get a price quote for a service

curl -X POST http://localhost:8000/api/quote \ -H "Content-Type: application/json" \ -d '{"service_type": "resume_optimization", "customer_email": "test@example.com", "input_data": {}, "rush": false}'

POST /api/create-order

Create a new order (demo mode without payment)

curl -X POST http://localhost:8000/api/create-order \ -H "Content-Type: application/json" \ -d '{"service_type": "business_name", "customer_email": "test@example.com", "input_data": {"industry": "tech", "description": "AI startup"}, "rush": false}'

GET /api/job/{job_id}

Check job status and get results

curl http://localhost:8000/api/job/YOUR_JOB_ID

GET /api/stats

Get system statistics

curl http://localhost:8000/api/stats
